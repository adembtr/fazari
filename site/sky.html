Pick any point of the sky. This page finds the SPHEREx exposures that cover it, reads only the needed rows of each image from the public archive on AWS (HTTP Range), and builds an aligned blink of the observing seasons in your browser. Moving stars jump; everything else stays still.

What is here

Over time

One SPHEREx image per visit, shown in turn: stars stay still, something that moves jumps.

SPHEREx sees infrared light the eye cannot. Each button shows the same spot in another infrared colour; some objects only show in one of them.

What changed between two visits

The last visit minus the first. Still stars cancel out; something that moved leaves a blue spot (where it was) and a red spot (where it is now).

Verdict

What the images say about this spot, and how fast something would have to move for us to notice it.

Measurement

Our number, measured from these images alone, next to what the star catalogue says about the same object.

Spectrum

How bright this spot is in each infrared colour. Every exposure sees it in a different colour, so the exposures together draw the curve.

Brightness over time

Did this spot get brighter or fainter between the visits? Each measurement is divided by this spot's own average brightness at that colour, so a steady source stays near 1.

Small print

For those who want to check: what was downloaded, the technical numbers of the measurement and the settings of this run.

Wavelength

Each bin uses one detector; about 2.5 MB per exposure. Work runs in a background thread.
