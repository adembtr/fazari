    How to read a blink

    1. 1. Pictures flip back and forth

      A blink shows the same patch of sky, photographed months apart, one after the other. Your eye catches anything that changes.

    2. 2. Still dots are the background

      Almost every star and galaxy is so far away that it never seems to move. If a dot stays put, it is background.

    3. 3. A dot that jumps has moved

      A small, steady step is a nearby star or brown dwarf crossing the sky. A big jump, or a dot that is there only once, is usually an asteroid.

    4. 4. Same place, new brightness: a variable

      If a dot stays in place but grows brighter or fainter, it is a variable star, like a pulsing red giant or a young star behind moving dust.

    5. 5. Some changes are not real

      Cosmic-ray hits, satellite trails and glitches near image edges appear in just one picture. A real object shows up in several pictures and wavelengths.

    Spotted something odd? Call it a candidate, not a discovery. Astronomers check it against star catalogues (like Gaia and WISE) and more data first. That is how real science works.
